# known_sqllogictest_divergences.txt — per-assertion sqllogictest divergence allowlist
#
# Each entry is "<relative-test-path> <query-start-line>": a single sqllogictest
# query record where real-doltlite's result differs from stock SQLite's. The
# line number is the 1-based line of the "query ..." header within the test file
# (stable because the corpus is pinned to a fixed Fossil check-in in CI — see
# .github/workflows/test.yml).
#
# run_sqllogictest.sh gates bidirectionally, exactly like run_testfixture.sh:
#   (1) every doltlite divergence must be listed here, and
#   (2) every listed entry must still diverge.
# So a NEW divergence in any clean file fails CI, and a listed entry that starts
# matching stock again must be removed.
#
# There are currently NO known divergences: real-doltlite matches stock SQLite on
# all corpus files. (The previous index/delete entries were the #1151 churn bug,
# fixed by #1152.) Add an entry here only for a genuine, intentional divergence.
