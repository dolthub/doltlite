# Each line is "<relative-test-path> <query-start-line>": a single sqllogictest
# query record where real-doltlite's result differs from stock SQLite's. The
# line number is the 1-based line of the "query ..." header within the test file

# .github/workflows/test.yml).

#   (1) every doltlite divergence must be listed here, and
#   (2) every listed entry must still diverge.

# entry that starts matching stock again must be removed.
